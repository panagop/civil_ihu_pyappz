# Αντίγραφα ασφαλείας των πινάκων `mitroa_*`

Εδώ καταχωρούνται τα zip που παράγει το κουμπί «Αντίγραφο ασφαλείας της βάσης
(CSV)» στην ενότητα του συντονιστή της καρτέλας «Προετοιμασία <έτους>» της
σελίδας 5. Ένα CSV ανά πίνακα (`mitroa_external_electors`, `mitroa_proposals`,
`mitroa_year_status`, και όσα `mitroa_backup_*` υπάρχουν ακόμη), UTF-8 με BOM.

Η βάση στο Railway δεν είναι προσβάσιμη από πουθενά αλλού και το σύστημα
αρχείων του container είναι εφήμερο, οπότε το κατέβασμα και η καταχώριση εδώ
είναι ο μόνος τρόπος να υπάρχει αντίγραφο έξω από τη βάση. Κρατήστε το
όνομα που δίνει η εφαρμογή (`mitroa_db_<ΗΗΜΜΕΕΕΕ-ΩΩΛΛ>.zip`).
